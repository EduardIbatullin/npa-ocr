<|ref|>equation<|/ref|><|det|>[[390, 83, 603, 140]]<|/det|>
\[Z_d = \frac{\sum_{j=1}^{w} S_j}{\sum_{j=1}^{w} V_j} \times 100\%,\]

<|ref|>text<|/ref|><|det|>[[174, 153, 222, 172]]<|/det|>
где: 

<|ref|>text<|/ref|><|det|>[[114, 174, 884, 237]]<|/det|>
w - количество участков недр, предоставленных в пользование, за исключением участков недр, соответствующих положениям абзаца третьего пункта 3 настоящих Правил; 

<|ref|>text<|/ref|><|det|>[[114, 236, 884, 369]]<|/det|>
S_j - объем сожженного на факельных установках и (или) рассеянного попутного нефтяного газа, добытого на j-м участке недр, за исключением объемов сжигания попутного нефтяного газа при плановой остановке газоперерабатывающих мощностей, определенных в соответствии с пунктом 6 настоящих Правил, тыс. куб. метров; 

<|ref|>text<|/ref|><|det|>[[114, 367, 884, 415]]<|/det|>
V_j - объем попутного нефтяного газа, добытого на j-м участке недр, тыс. куб. метров. 

<|ref|>text<|/ref|><|det|>[[114, 416, 884, 501]]<|/det|>
23. В случае если интегральный показатель сжигания не превышает предельно допустимого значения показателя сжигания, для каждого участка недр дополнительный коэффициент (К) к ставкам платы за выбросы не применяется. 

<|ref|>text<|/ref|><|det|>[[114, 501, 884, 587]]<|/det|>
24. В случае если интегральный показатель сжигания превышает предельно допустимое значение показателя сжигания, плата за выбросы исчисляется по каждому участку недр на основании значения фактического показателя сжигания для этого участка недр. 

<|ref|>text<|/ref|><|det|>[[114, 586, 884, 634]]<|/det|>
25. Фактический показатель сжигания (Z_j) для участка недр определяется по формуле: 

<|ref|>equation<|/ref|><|det|>[[415, 640, 581, 689]]<|/det|>
\[Z_j = \frac{S_j}{V_j} \times 100\%.\]

<|ref|>text<|/ref|><|det|>[[114, 700, 884, 765]]<|/det|>
26. Показатель покрытия затрат (I<sub>пн</sub>), используемый для расчета дополнительного коэффициента (К) для пользователя недр, определяется по формуле: 

<|ref|>equation<|/ref|><|det|>[[448, 771, 546, 812]]<|/det|>
\[I_{пн} = \frac{C_t}{P_t},\]

<|ref|>text<|/ref|><|det|>[[114, 844, 884, 912]]<|/det|>
C_t - затраты, понесенные пользователем недр на реализацию проектов по полезному использованию попутного нефтяного газа в отчетном периоде (t), тыс. рублей;

# Правила работы с OCR

- Результат распознавания формируется только автоматическим конвейером.
- Запрещены ручные/точечные правки DOCX, постраничных результатов, подстановки
  по имени или хешу конкретного PDF и файлы индивидуальных исправлений.
- Исправлять ошибки можно общими правилами кода с проверкой отсутствия регрессий.
  Эталоны конкретных документов допустимы только в тестах, не в runtime.
- Неустранённые ошибки сохраняются в автоматическом результате и отчёте контроля;
  их причины и примеры записываются в `docs/open-questions.md`.
- Три открытых направления: рукописный текст; дополнительное чтение
  `[не распознано]`; мелкие ошибки, не меняющие смысл документа.
- Ручная сверка служит для выявления ошибок и подготовки тестов, а не для правки результата.

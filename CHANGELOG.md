# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[семантическому версионированию](https://semver.org/lang/ru/). Ход разработки и
эксперименты — [`docs/history/plan.md`](docs/history/plan.md).

## [Unreleased]

### Добавлено

- Движок таблиц `vlm` (`--table-engine vlm`): DeepSeek-OCR в vLLM на GPU со
  структурой по линиям разлиновки скана; при недоступности vLLM документ
  дораспознаётся движком `tatr`.
- Шлюз `npa_ocr.vlm_gate`: запуск vLLM по первому запросу и остановка после
  простоя, для общей GPU.
- Повторное чтение сомнительных ячеек таблиц DeepSeek-OCR по фрагменту ячейки.
- Сшивка таблиц, продолжающихся на следующей странице.
- Поворот страниц-сканов по Tesseract OSD (`--no-auto-rotate` отключает).
- Удаление текста штампов, печатей и подписей по трём прочтениям страницы
  (qwen3-vl, Tesseract, DeepSeek-OCR) с дописыванием шапки органа.
- Второе прочтение текста по DeepSeek-OCR: римские цифры и их диапазоны,
  латинские переменные, индексы и степени, цифры, слитые со словами.
- Формулы в DOCX — формулы Word (LaTeX → MathML → OMML); индексы — подстрочным и
  надстрочным шрифтом.
- `constraints.txt`: закреплённые версии всех пакетов образа.
- Справочник [`docs/architecture.md`](docs/architecture.md).

### Изменено

- Базовый образ закреплён: `python:3.12.15-slim-trixie` (Tesseract 5.5.0).
- Зависимости в Dockerfile ставятся до копирования кода: правка кода не
  вызывает переустановку зависимостей.
- Докстринги приведены к стилю Google; README переписан; журнал разработки
  перенесён в `docs/history/`.

### Исправлено

- Страницы, распознанные запасным движком `tatr`, не берутся из сохранённых
  результатов при следующем прогоне с `vlm`.

## [0.1.0] - 2026-10-25

Первая версия как самостоятельного проекта (выделен из npa-pipeline).

### Добавлено

- Распознавание сканов в DOCX: Tesseract для текста, TATR для структуры
  таблиц, PaddleOCR для областей таблиц, абзацы по геометрии, колонтитулы.
- Сохранение результатов страниц и продолжение прерванного распознавания;
  тайминги шагов; защита от нехватки памяти.
- Docker-образ с моделями, загруженными при сборке.
- HTTP API асинхронных заданий; автоматический повтор задания, упавшего по
  сигналу.
- ИИ-эскалация (`--ai-escalation`): восстановление текста под печатью и
  штампом через qwen3-vl в Ollama, удаление служебных меток.
- Восстановление формулы должности подписанта по `--authority-name`.
- Перепроверка подозрительно узких таблиц и страниц без найденных таблиц через
  img2table.
- Дочитывание нижней полосы страницы, пропущенной сегментацией Tesseract
  (строка подписи).

### Изменено

- Текст ячеек таблиц читает RapidOCR (ONNX Runtime) вместо PaddleOCR: не
  падает на CPU без AVX2.
- PPStructureV3 загружается, только если TATR нашёл таблицу.

### Исправлено

- Падения с SIGILL на CPU без AVX2: отключён oneDNN в torch, PaddlePaddle
  проверяется в подпроцессе, при его недоступности текст таблиц читает Tesseract.
- Ложные таблицы TATR на обычном тексте: проверка заполненности сетки,
  отбраковка 1×1, слияние дублирующихся областей.
- Метка «table rotated» и запасной порог детекции для таблиц во весь лист.
- Ложные объединения ячеек и слишком высокие строки TATR.
- Двойная детекция надстрочной цифры; склейка соседних слов без пробела.
- Ошибка классификации метки (таймаут Ollama) больше не роняет документ;
  короткий ответ VLM не заменяет настоящий текст.
- Словарь исправлений известных искажений OCR применяется и к обычному тексту.
